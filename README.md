# 入画 · Living Landscapes

一座用 Three.js 实时生成的风景画馆，在电脑和手机上游览九个绘画与实景世界。

- 七个绘画世界，加上张家界峰林与桂林漓江，各有地形、配色和章节。
- 展卷、自由轨道漫游、陆地步行；章节导航、小地图、自动游览和触控方向键。
- 冷暖夜景、流动薄雾、近景模型、高画质阴影与自托管中文宋体。
- 帝国的五个时代切换会改变建筑，不只是改变画面颜色。
- 每景独立配乐与场景音效、分轨调音，取景保存和带声音的 24 秒 WebM 导出。

## 启动

需要 Node.js 22.12+。

```sh
npm ci
npm run dev
```

```sh
npm run lint
npm test
npm run build
npm run preview
```

这是依据原画的构图、色彩与主题创作的三维意境演绎，不是原画的逐笔复原。所有模型和选择页预览均由程序生成；无馆藏图像贴图、无远程模型依赖、无分析跟踪。

架构、操作、音频、字体再生成和部署见 [项目文档](docs/PROJECT.md)；场景取舍见 [美术方向](docs/ART-DIRECTION.md)。
