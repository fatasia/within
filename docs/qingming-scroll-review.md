# 清明上河图：整卷空间核查

2026-10-16。范围：`qingmingScroll.ts` 的卷首、河岸与卷尾补充；屋顶、城市主体和人物动效由其他改动负责。

## 对照依据

- [故宫博物院藏张择端《清明上河图》](https://www.dpm.org.cn/collection/paint/228226.html)：北宋原本，绢本淡设色，24.8 × 528 厘米。不是清院本，也不是现代主题公园。
- [故宫讲坛：北宋张择端《清明上河图》揭秘](https://www.dpm.org.cn/forum_detail/99722.html)：城郊、虹桥上下、城墙内外三个主要部分；河岸与街道柳树、港湾及舟运承担空间联系。
- 实际查看了本地 `public/originals/qingming-section-1.webp`、`qingming-section-2.webp`、`qingming-section-6.webp`。卷首为疏树、村舍、土路、小型跨沟桥，卷尾为层叠商铺、院落和街巷。未把现代开封街景当成原画。

## 本次落地

| 原有缺口 | 实际修改 |
| --- | --- |
| 村舍之间缺少连接，郊野仅五株树 | 增加弯曲土径、分岔入村小路和七株疏树；全部共用现有材质合批。 |
| 卷首跨沟细节缺席 | 增加短木板桥及浅干沟；桥面仅高出地面 0.2 米以内，未新增水面。 |
| 村落到码头过渡空白 | 增加路边小茶棚、矮凳、碗、店主；码头后侧增加捆扎货包、系缆柱和绳圈，避让岸边通道。 |
| 城内末段只有孤立小院 | 补三条后巷、两处小型作坊棚、两名住户，与现有街屋和卷尾院落衔接。 |
| 疏树像齐刷刷扫帚 | 改为不对称弯曲主枝、向外散开的细枝、分叉及露根；保留早春疏枝而非盛夏浓冠。 |

细草杆和细枝改成无端盖三棱柱，未增加材质类别。新增细节后全城市静态/动画网格合计 **446,411 三角形 / 25 个网格**（同会话其他清明修改会改变最终数值）；本任务接手时为 **447,114 / 25**。不是靠增加 GPU 负担换取细节。

## 仍有差距

这是一版按原作段落组织的三维空间解释，不是逐屋逐人等比例复原。城市主体仍复用部分建筑模板，街坊密度与原图存在差异；本轮已调整主街、河道和十栋建筑的位置，但仍不是逐幢测绘复原。当前默认近景主要呈现虹桥，不能代表整卷；全卷俯瞰应作为另一个视角，不宜替代近景细节检查。

## 用户补充参考：搜狐全文与图片复核

[上海书画出版社在搜狐刊载的全卷文章](https://www.sohu.com/a/217784892_369578)已读取，并实际查看了其连续画心图片与紧随其后的题跋。其画心与本项目六段北宋原图是同一版本，未发现一段额外的建筑景观。该文强调的是装裱及题跋完整收录；文中关于画心、全卷长度的说法与故宫著录口径不一致，尺寸仍以故宫藏品页为准。

按图片从卷首至卷尾，空间对应为：郊野疏林与低村舍 → 河岸店舍及密集泊船 → 虹桥交汇 → 桥后沿河街道逐渐离开河岸 → 斜向入城道路与门楼 → 密集店铺街市和院落。它不是“整齐平行三排房屋 + 河道从头到尾居中”的构图。

下一步主体修订的具体次序：
1. 河运段增加靠岸泊船的成组感，但不要令所有船同向等距；城内末段减少主河道视觉权重。
2. 街道应从桥头扩展、逐渐收束入门，再在城内打开；后巷与房屋形成斜向、错落的街坊。
3. 城门楼上应读作有柱廊的木构厅楼，不是仅有几个窗洞的封闭墙盒。
4. 民居屋顶形成穿插前后层次，作坊/铺棚贴着街缘，不能用孤立均匀网格代替。
5. 郊野保留树间空地，但老柳自身应有密集细枝；当前模型细枝密度仍简化。

参考文件仅存放在 `artifacts/originals/sohu-*.jpg` 用于核查，未拿出版社图片替换产品中的原作资源。

## 主体布局修订（2026-10-16 后续）

- **桥头到城门**：新增一条从虹桥北桥头转入城门轴线的连续主街，桥头较宽、入门收束。沿街房屋和摊铺同步转向；四名步行者改走这条弯曲街道，货车保留原有 -45m 工作车道，未移动城门与原有欢门、运输表演坐标。
- **河运**：保留总船数，五艘现有船集中到西段两岸，位置、朝向、大小不等距；靠岸工作船改为卷帆，减少七艘船同时张满帆的重复感。原桥下过船仍在原航道，船体微动与水线保持对齐。
- **城内**：把七栋原南岸建筑和三栋城外后屋重新放入城内街坊，形成主街两侧、错落后巷和更密的屋顶层次；没有增加一批高开销房屋。既有院落、巷道、欢门、驴车位置保留。
- **河道收卷**：河道从 x=30 后渐离市街，在城尾向外偏移约 52m，城内机位由屋顶和街巷主导。两岸土路由方块改连续曲带，石岸按河道切线转向；地形、水面遮罩、岸边人物与静泊船共用同一河道函数。
- **门楼与疏柳**：门楼中部改为半墙、立柱、梁托围合的木构厅廊；柳树垂梢由每树 15 组增至 25 组，减少单梢圆周段数，早春疏树细枝由每主枝 6 组增至 8 组。
