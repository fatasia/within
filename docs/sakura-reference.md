# 樱谷资产

樱谷复用 [Sakura Fantasy](https://github.com/billpwchan/sakura-fantasy) 的树木生成器、人物、篷舟与部分贴图，上游版本为 `9f2093e8e61d2f4c7eafe92b8d52464ceb11439b`。

- 代码许可：[MIT](../public/assets/sakura/LICENSE)。
- 模型、扫描纹理和第三方资产来源：[上游署名](../public/assets/sakura/UPSTREAM-CREDITS.md)。
- 原人物基于 MPFB2 / MakeHuman 的 CC0 人体，植物扫描来自 ffish.asia / floraZia；具体条款以资产署名为准。

项目调整了材质、光照、航线、水面裁剪和资源加载，并增加跟拍与乘舟视角。第三方资产不因仓库采用 MIT 而改变原有许可。
