# 西湖与黄山：建模依据及验收

这两景以实地的建筑形制与植被、地貌类型为依据，采用压缩距离的浏览器展陈。当前不是测绘比例或全景摄影复刻。

## 已核对的地图与照片

- [西湖遗产地图入口](https://whc.unesco.org/en/list/1334/maps/)与[2011 年范围图](https://whc.unesco.org/document/115494)：用于继续核对湖岸、堤、山岸的关系；2023 年 PDF 超出网页读取大小限制。
- [西湖 UNESCO 说明](https://whc.unesco.org/en/list/1334/)：三面山、湖、堤、岛与寺塔共同构成文化景观。
- [雷峰夕照实景照片，王华，2008](https://whc.unesco.org/en/documents/114945)：已在官方图库打开查看。塔位于连贯的山岸林线之后，不是孤立湖心岛。模型已把圆岛改成与后方山岸相连的夕照山岸，并增加岸林。
- [黄山遗产地图入口](https://whc.unesco.org/en/list/547/maps/)：地理范围依据，尚未把等高线或真实游线转换成场景坐标。
- [黄山实景，Francesco Bandarin，2004](https://whc.unesco.org/en/documents/110966)：已在官方图库打开查看。依据其横向分层的松冠、可见针叶与裸露的倾斜花岗岩面，替换了球状松冠并加宽主峰山体。

照片只用于观察，没有打包进项目或作为贴图分发。现有几何和岩粒贴图均程序生成。

## 本轮实现

西湖：低弧单孔石桥、五层八角塔身和外廊、林岸、垂柳与荷塘；白娘子和许仙在桥上同伞，法海在远岸。桥面高度与 `xihuGroundY()` 同源。柳枝缓摆、带舟子的摇橹船沿闭合湖面路径行驶，避免计时取模造成突然回跳。内部不创建第二张水面。

黄山：层叠花岗岩峰体、开放针叶扇簇、横展松枝、石质平台、四层缓慢流动的云海。修复云层低于通用地板而被全部遮挡的问题。岩面有确定性微颗粒贴图与凹凸；峰体不再是开口山筒。

地理限制：为了保留现有镜头和漫游配置，断桥与雷峰塔仍压缩到同一构图内；断桥北端的短连接堤是展陈组织，不对应真实断桥到雷峰塔的路径。黄山峰位也不是莲花峰、天都峰等峰的真实坐标。后续严格地理版本需同时更新地形、路线和镜头，不能只改标签。

## 验证

```powershell
npx tsc --noEmit
npx vitest run src/engine/featuredLandscapes.test.ts
node scripts/review-landscapes.mjs
```

- 3 项定向测试覆盖桥面高度、五层塔、人物相对位置、场景动画、有限顶点及几何预算。
- 几何预算计入实例展开：西湖 < 250,000 三角形，黄山 < 350,000；静态网格按材质合批。
- 截图使用实际 Experience 渲染管线，包含全局水面、阴影、雾与后处理。5 个镜头保存在 `artifacts/landscape-review/`，控制台错误为零。
- `metrics.json` 中的 draw calls / triangles 是离线完整渲染计数，包含额外渲染通道，不是实时 FPS。

建议总览镜头：西湖 `eye [28,18,48] → target [0,9,-24]`；黄山 `eye [32,24,72] → target [-8,27,-35]`。原西湖远景会将大量空前岸放进画面。

### 第二轮复检

地面代理已接入 `terrain.ts`：断桥中心高度 2.4、夕照山岸 0.8，测试同时验证实际 `groundHeight()` 调用。垂柳增加上部冠层与下垂叶密度；叶片使用二三角实例、细枝使用三边截面，在加密后保持原几何预算。江南远山降低高度，黄山平台补岩粒表面，云层减少白色不透明叠加。

离线脚本现在每镜头预热后测 7 次 GPU 同步帧，分辨率 1600×1000。最近一轮中位值：西湖总览 17.2 ms、桥 17.4 ms、塔 21.0 ms；黄山总览 13.4 ms、松 14.3 ms。同步开发进程和 GPU 争用会影响结果；这是短样本，不用于保证所有设备实时帧率。当前实景细节仍需继续逐镜头精修，不用“完美”或“全图实测还原”描述。
