# 武汉桂雨：磨山空间参考

这份资料用于把桂雨意象落在可信的东湖环境里：保留小雨、桂香、安静游览的艺术构图，采用真实山岸、道路与林冠关系，不做整园测绘复刻。核查日期：2026-10-16。

## 先确定场景范围

- **已确认地点**：磨山北门、友谊林、桂花园属于本次取材范围。2024 年现场报道描述了北门两侧丹桂、继续前行到友谊林的赏桂体验；报道不提供路线方位、距离与园界。[武汉市政府转载长江日报，2024-10-12](https://www.wuhan.gov.cn/zjwh/whly/202410/t20241012_2467368.shtml)
- **地图锚点**：高德的北门 POI 名称、地址与经纬度页面已打开。地址标为磨山景区西北角；纬度 30.553341、经度 114.407425。按高德 GCJ-02 坐标使用，不能直接冒充 WGS84 或工程测量点。本轮未读取可测量的卫星底图。[高德北门 POI](https://www.amap.com/place/B0FFFTJPE6)
- **道路连通性**：2024 年官方徒步报道给出的顺序是友谊林出发，经北门、楚城、凤标、楚才园、离骚碑，再走环山路登楚天台。可证实这些空间由步行线路联系，不能由文字还原每段曲线。[武汉市政府转载长江日报，2024-04-25](https://www.wuhan.gov.cn/sy/whyw/202404/t20240425_2393944.shtml)

## 可以直接采用的五条空间规则

1. **湖是大开面，岸是局部转折。** 用一个浅湾、一个低缓凸岸建立节奏，远岸低而远；避免周期相同的正弦岸线与等距小山。
2. **桂树不等于所有树林。** 花枝近景用深绿厚叶与小簇丹桂，后面保留混合林冠、明暗空隙；不要把整片林子染成金黄花球。
3. **主路、林间小径、滨水步道不是一条线。** 主路退后，支路接入树下与岸边，局部平台让视线打开；不必让所有镜头都站在水边。
4. **驳岸低、材料有段落变化。** 低石岸、草坡、少量景石、局部台阶与木板步道分别出现，使用人物尺度校验，避免连续高城墙或整圈巨石。
5. **建筑藏在林后，景物不是古亭陈列。** 先做一处低调休息构筑物，留树冠和湖面为主角。现阶段它只能叫场景中的休息处，不冠以未经核实的真实亭名。

上述是基于照片的设计转译，不是对实地尺寸的测量。小雨、湿石、檐滴、花落与雾可以保留；照片没有证明这些特定地点在同一时刻出现上述天气效果。
