# 三幅山水的还原核对清单

这份清单供模型、材质和镜头验收使用：先对齐画面结构，再决定近景做什么。核对日期：2026-10-16；记录的是当时工作区代码，不是上线画面的验收结论。

## 本轮修订

溪山已移除通用帆船与拱桥，九座模板亭屋改为一处林间檐屋，右前景改为三头驮兽和两位成年行旅，并重定近景镜头。数量与衣冠为场景编排，尚未逐一核对原画局部。以下缺项记录保留用于后续复核。

## 先修这三项

1. **溪山：从“江上游山”改回“巨壁下的行旅”。** 本轮修订前，共用装配给溪山放入五艘高帆江船、一座同款石桥、九座亭屋，近景章节又重点拍桥和亭。这些模型有细节，但不能替代原画的纵向巨壁、右侧细瀑、近岸大石与微小驮队。先重排主峰、右下树石与驮队的投影关系，取消没有局部证据的显眼江船，再定镜头。
2. **千里：恢复长卷的分段连接，不再是一排同类山包。** 当前九个程序山体和一座短桥没有建立原卷六段的对应关系。先画出分段山形、岸线、桥与水路的关系图，再造主峰和连接建筑；加瓦、加草不能补救这个构图差异。
3. **富春：恢复折面山形、疏密节奏和纸墨层次。** 已查看的局部不是一串低缓圆丘：一座较挺拔的山体压住近景，斜向皴线与层层退后的坡岸组织画面。现有径向缓丘、统一亭屋和灰绿材质应分开处理；先确定具体临摹段落，再调整山形和留白，不继续均匀撒树。

以上为初次审计的修复优先级。后续集成已检查 `artifacts/restoration-review/xishan-0.22.png` 与 `xishan-0.43.png`，修复驮队穿石、脚下陡坡和屋檐接缝；未录制视频。

高清资料补充：已下载馆方 [溪山 1776×3889 图像](https://theme.npm.edu.tw/selection/att/collection/04000959/17009764.jpg) 并检查整体构图；富春首段 3663×1993 图像已缓存，17幅分段链接已从馆方页面整理，尚未完成全部局部核对。

## 近景验收必须分两条线

### A. 还原依据

- [ ] 每个主角模型有 `画作 / 原图局部 / 识别把握 / 模型函数 / 场景坐标` 记录；没有证据的保留为待核。
- [ ] 对比原画时固定时间、曝光、雾与参考机位；先看轮廓、遮挡、比例、色块，再看表面细节。
- [ ] 长卷允许分段视点，不强行把全卷塞进单一透视；每次近景后有中景交代该物在山水里的位置。
- [ ] 灯笼、月夜、飞鸟、自动变化的日照、配乐和隐藏女性属于体验层；除非有对应证据，不纳入“原画细节已复原”的统计。隐藏女性来自用户新增要求。

### B. 模型与交互质量

- [ ] 在 2–5 米近景检查瓦、栏、绳、枝等是否真实相连、有正确法线、没有悬空与交叉；低模接缝不能靠雾遮住。
- [ ] 人眼高度约 1.7 米复看近景；相机贴近并不自动有“人尺度”，台阶、门洞、船板与人物必须相互一致。
- [ ] 同一对象在近、中、远景保持形状与色相，不因转动突然变成圆饼、白片或一团黑。
- [ ] PC 与手机分别验画面主题、控制区遮挡、可读轮廓；不要求手机复制横屏裁切，但不能丢掉本章主体。
- [ ] `cinematography.test.ts` 只证明坐标、距离、地形净空等数值条件；`pineGeometry.test.ts` 只证明几何、实例化和预算约束。它们均不证明视觉相似或没有遗漏。
