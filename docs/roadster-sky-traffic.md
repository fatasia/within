# Roadster 空中车流

虚构赛博试场新增蒸汽飞行车辆，独立于玩家车辆和碰撞系统。

- 双向分层航线，最低中心高度约7米，高于主车短跃区域；随时间缓动。
- 共8辆共享车体、玻璃、升力喷口及灯带；低画质3辆、均衡5辆。
- 四组实例化车辆与一组蒸汽点云，总计5个额外绘制批次。无额外光源、阴影或下载模型。
- 蒸汽按历史航迹生成，向下漂移、扩散并淡出；不依赖每帧新建几何体。

跟车镜头稍拉远并抬高观察点，给车流留出背景；章节过渡连续性测试通过。227项单元测试、lint、TypeScript和构建通过；本机浏览器未发现着色器或页面错误。未测真实手机帧率。
