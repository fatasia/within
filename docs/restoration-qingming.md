# 清明上河图：原作对照与建模缺项

这份清单用于安排清明场景的下一轮建模和近景验收，不把“存在同类模型”当作“已经忠实还原”。核对日期：2026-10-16。

**结论：当前是按郊野、汴河、虹桥、城门、市井组织的艺术化场景，尚未建立原画局部与模型逐项对应的证据。** 主体类型大多存在，但关键事件、建筑差异、交通与人物职业群像仍缺失。清单覆盖本轮能够核实的内容，不是全卷元素的穷尽目录。

## 本轮修订

虹桥附近已补专用工作船、卧桅、收帆绳和三名固定姿态船工；净空和水线检查通过。该组按过桥事件补作，具体船型、衣冠、人数及桥侧围观仍待高清局部核对。下文缺项是本轮改动前的审计记录，不能视为最终验收。

## 三项优先建模差距

1. **虹桥降桅过船与围观事件。** 原作证据明确，当前却没有。先建立船、可读的降桅状态、操作船工和桥边响应人物的整体关系，再核木拱节点。验收以桥侧近景和桥下净空为准，不以新增模型数为准。
2. **一处有原画对应的大店欢门与相邻小铺。** 当前最强的近景仍是通用铺面。先补原画局部标注，做入口、门窗、牌招、货品和职业人物的完整组合；它能直接检验“细节是否属于这幅画”。
3. **砖门楼—板筑土墙—门前交通组合。** 先纠正材料和结构混用，再选一组有图像证据的牵引交通。门洞本身、墙体夯层、运载工具与人与物的关系，应在一个镜头内同时成立。
