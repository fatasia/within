# Roadster 车壳修复

依据用户提供的银色楔形车身四视图调整程序化模型，未更换为旧款红色 Roadster。

- 非平面侧壳不再用整面扇形三角化；轮拱上下边界之间使用短网格带，避免巨大尖三角反光。
- 连续车肩替换独立尖翼，删除重叠前翼面；轮拱添加随外壳收窄的黑色内衬，避免圆筒穿出引擎盖。
- 前脸下沿闭合，补齐后侧窗与后风挡之间的 C 柱板；玻璃增加深度写入，外视角不再明显看穿车顶。
- 车头仍为 -Z，车顶最高点仍为局部 y=1.245；车顶角色脚位 y=1.255 不变。轮胎底部局部 y=0，与场景地面高度匹配。

## 检查

运行 `node scripts/review-roadster.mjs`，前、侧、后、座舱、喷气、抓地共六张实际渲染，输出至 `artifacts/roadster-review/`，浏览器错误为空。前/后视图已逐图检查，原巨大侧翼与穿出引擎盖的轮拱内衬已消除。

1600×1000 离屏完整场景为 88–106 draw calls，约 6.7–13.2 万渲染三角形（含阴影遍次），不是单车网格数或 FPS。

`roadster.test.ts`、`roadsterSurface.test.ts`、`polarScenes.test.ts` 共 14 项通过，TypeScript 与模型 ESLint 通过。新增回归检查限定侧面三角形纵向跨度不超过 0.032，保证轮拱空间；同时检查 Arctic 熊/企鹅根的 encounterId 和关节层级。

当前是参考图驱动的轻量程序模型；曲面、内饰和材质精度仍不等于厂家 CAD 或实拍。
