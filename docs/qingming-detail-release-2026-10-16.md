# 清明市井细节更新 · 2026-10-16

本轮把沿街房盒改为有内部陈设的铺面，保留全卷游览路线。仍是依据画作的三维演绎，不是逐人物、逐建筑的 1:1 复原。

## 这次改了什么

- 49 处开放铺面，分酒肆、茶食、药铺、布帛、竹木、纸铺、米行、客舍八类；加入酒坛封口、蒸笼、药柜、布匹、纸张、米斗和卧榻等陈设。
- 新增 64 名顾客、3 峰驮货骆驼、1 名引领者、4 名搬运工和 4 名店家。交谈、劳作和驮队动作合为一个骨骼批次。
- 补充 4 处码头货场、1 处修船架、3 处井栏农圃、3 处城内工作院落；临街加布篷和开启的门板，后院补低屋并封闭山墙。
- 展卷增加驮队和店铺近景，夜段提高环境补光，避免新陈设淹没在阴影里。清明预览图与中文字体重新生成。

## 资料与取舍

参考用户提供的[全图](https://www.sohu.com/a/217784892_369578)及故宫[藏品介绍](https://www.dpm.org.cn/collection/paint/228226.html)。保留郊野、河运、虹桥、城门、市井的阅读顺序。店铺类别、陈设和后院是场景化补充，不据此认定画中某一间店的具体身份。大部分街路保留土路，仅城门附近有铺石。
