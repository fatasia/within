# 清明网页版写实重建：街市与材质

用户确认保留手机网页版。本轮集中修改虹桥到城门的街市与城内酒肆，仍是阶段成果，不是全卷逐物复原。

- 北侧店铺随弯曲街道排列，修正两侧建筑朝向；摊位沿店前布置，不再排在固定直线上。
- 六座重复房屋替换为五开间、两层通廊的商宅及三个后院配屋；补充窗格、栏杆、柱础、斗栱形构件和陶器。结构参照全卷城内段，尺寸与隐蔽侧面为推演。
- 木、瓦、石、土、灰泥共用五组256px色彩/凹凸/粗糙度贴图；调整日光、天空、雾和材料颜色。
- 阴影范围随观察位置收紧，减小悬浮偏移。清明均衡画质启用1024px阴影，高画质2048px；手机阴影仍按12Hz刷新，人物逐帧更新。
- 开场改为虹桥河市中景，保留之后的郊野—汴河—虹桥—城门—城内顺序与原时间轴；商宅窗光对齐窗格，昼夜动画保留。
